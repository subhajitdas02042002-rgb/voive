How it works

  1. 1

    Drop in the script

    Add <script src="voice-assistant.js"></script> before your closing </body> tag.

  2. 2

    Visitor clicks the mic

    A floating button appears automatically. Clicking it asks for microphone permission, once, in-browser.

  3. 3

    It listens and responds

    Speech is matched against your command list and answered out loud using the browser's built-in voice.

Get it

Copy the file, add the tag. That's the whole setup.

<script src="voice-assistant.js"></script>

Works in Chrome, Edge, and Safari. Requires HTTPS or localhost, since browsers block microphone access on plain HTTP.

Built with the Web Speech API. No tracking, no server, no cost.
